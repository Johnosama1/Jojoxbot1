Build a Telegram bot with a centralized verification system that enforces channel subscription after task completion, including protection for WebApp (Mini App) access.

========================
CORE REQUIREMENT

Verification must run in ALL entry points:

- /start command
- Any button click (callback_query)
- Any bot command
- Any API endpoint
- Telegram WebApp (Mini App) loading

No bypass allowed.

========================
DATA MODEL

user = {
userId,
tasksCompleted: boolean,
isBlockedForLeaving: boolean,
rewarded: boolean
}

requiredChannels = [
{ id, username, inviteLink, title }
]

========================
GLOBAL VERIFICATION MIDDLEWARE

Create a function:
verifyUserAccess(userId)

Logic:

1. Load user data

2. IF tasksCompleted == false:
   → ALLOW ACCESS مباشرة (no restriction)

3. IF tasksCompleted == true:
   → Loop through all requiredChannels
   → For each channel:
   status = getChatMember(userId, channel.id)
   
    IF status NOT IN ["member","administrator","creator"]:
     → User left channel

     SET isBlockedForLeaving = true

     RETURN {
       allowed: false,
       missingChannel: {
         title: channel.title,
         link: channel.inviteLink
       }
     }

4. If all channels OK:
   → SET isBlockedForLeaving = false
   → RETURN { allowed: true }

========================
APPLY MIDDLEWARE (VERY IMPORTANT)

You MUST call verifyUserAccess() BEFORE executing ANY logic in:

1. /start handler
2. All callback_query handlers (buttons)
3. All commands
4. ALL backend API routes
5. WebApp initialization endpoint

========================
WEBAPP (MINI APP) PROTECTION

When user opens WebApp:

1. Frontend sends request:
   GET /api/verify-access?userId=XXX

2. Backend runs verifyUserAccess(userId)

3. If allowed == false:
   → RETURN:
   {
   allowed: false,
   message: "You must rejoin the required channel",
   channel: {
   title,
   link
   }
   }

4. Frontend behavior:
   IF allowed == false:
   → STOP loading app
   → Show blocking screen:
   "You must join this channel to continue"
   → Show button:
   "Join Channel"
   → Show button:
   "Check Again"
   
   IF allowed == true:
   → Load app normally

========================
BOT BEHAVIOR WHEN BLOCKED

If verifyUserAccess returns allowed: false:

- DO NOT execute any command
- Redirect user to task page
- Send message:

"You left a required channel. You must rejoin to continue."

- Show:
  - Channel name
  - Join button
  - Check Again button

========================
RE-CHECK FLOW

When user presses "Check Again":

- Run verifyUserAccess again
- If success:
  → Restore access
  → Send welcome message
- If still not:
  → Stay blocked

========================
ANTI-BYPASS RULE

Even if user:

- Opens bot from direct link
- Skips buttons
- Opens WebApp directly

→ System MUST still verify and block if needed

========================
GOAL

- No way to use the bot or WebApp after leaving channels
- Verification happens everywhere (bot + backend + frontend)
- Instant block and instant restore after rejoin
