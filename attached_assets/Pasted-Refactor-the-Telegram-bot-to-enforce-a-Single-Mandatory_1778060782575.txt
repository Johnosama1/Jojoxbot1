Refactor the Telegram bot to enforce a Single Mandatory Verification Gate that ALL entry points must pass through (commands, buttons, and Mini App).

================================
GOAL

No user can access ANY feature unless they pass a centralized verification check.

================================
CREATE CENTRAL FUNCTION

Create a server-side function:

verifyUserAccess(userId)

Logic:

1. Load user from DB

2. If tasksCompleted == false:
   return { allowed: true }

3. If tasksCompleted == true:
   For each required channel:
   status = getChatMember(userId, channel.id)
   
   If status NOT IN ["member","administrator","creator"]:
   return {
   allowed: false,
   missingChannel: {
   title: channel.title,
   link: channel.inviteLink
   }
   }

4. If all channels valid:
   return { allowed: true }

================================
ENFORCE GLOBAL GATE (CRITICAL)

You MUST create a wrapper/middleware called:

withVerification(handler)

Behavior:

- Extract userId
- Call verifyUserAccess(userId)

IF allowed == false:

- STOP execution
- Send blocking message:
  "You must rejoin the required channel to continue."
- Show:
  - Channel name
  - Join button
  - Check Again button
- DO NOT call handler

IF allowed == true:

- Execute handler normally

================================
APPLY TO BOT (MANDATORY)

Wrap ALL bot entry points:

- /start
- all commands
- all callback_query (buttons)

Example:

bot.on("message", withVerification(async (ctx) => {
// your normal logic
}))

bot.on("callback_query", withVerification(async (ctx) => {
// button logic
}))

================================
BLOCK DIRECT MINI APP ACCESS

Create API endpoint:

GET /api/verify-access

Steps:

1. Receive userId (or Telegram initData)
2. Call verifyUserAccess(userId)

If allowed == false:
return {
allowed: false,
message: "You must rejoin the required channel",
channel: { title, link }
}

If allowed == true:
return { allowed: true }

================================
FORCE MINI APP TO USE THE GATE

In Mini App frontend:

On app load:

1. DO NOT render app immediately

2. First call:
   /api/verify-access

3. If response.allowed == false:
   
   - STOP app
   - Show blocking screen:
     "You must join this channel to continue"
   - Show Join button
   - Show "Check Again" button

4. If response.allowed == true:
   
   - Load the app normally

================================
ANTI-BYPASS RULE

- User cannot access bot via:
  - deep links
  - commands
  - buttons
  - mini app direct open

Without passing verifyUserAccess

================================
DEBUG REQUIREMENT

Log every verification:

- userId
- channelId
- returned status

================================
RESULT

- All traffic (bot + mini app) passes through ONE gate
- If user leaves channel → instantly blocked everywhere
- If user rejoins → instantly restored
